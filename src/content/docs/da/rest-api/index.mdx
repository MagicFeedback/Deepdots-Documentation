Med Deepdots REST API kan dit backend sende feedback og holde dine CRM-kontakter i Deepdots opdateret uden at installere et SDK. Hvert kald er en almindelig HTTPS-forespørgsel med en JSON-body og et bearer-token.

## Hvad du kan

- **Send feedback** — én ad gangen eller i bulk, med svar, metrics og metadata.
- **Administrer kontakter** — opret eller opdater CRM-kontakter ud fra e-mail, med dine egne brugerdefinerede felter.
- **Knyt feedback til kontakter** — registrer, hvem der gav hver feedback.

Deepdots analyserer al den feedback, du sender: emner, sentiment, KPI'er og alt det andet, du ser i dashboardet.

## Base-URL'er

| Miljø | URL |
|---|---|
| Produktion | `https://api.deepdots.com` |
| Udvikling | `https://api-dev.deepdots.com` |

Brug udviklingsmiljøet, mens du bygger og tester din integration. Det har sine egne data og loginoplysninger.

## Det skal du have fra Deepdots

- En API-nøgle til hvert miljø, eller en API-bruger (e-mail og adgangskode), hvis du hellere vil logge ind.
- Dit `companyId` og `integrationId` for hver kilde, du sender feedback fra.

Din kontaktperson hos Deepdots giver dig alt dette, når din integration bliver sat op.
