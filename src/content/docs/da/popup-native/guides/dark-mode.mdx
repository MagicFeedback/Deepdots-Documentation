# Lys og mørk tilstand

Popup'en og surveyen i den henter deres farver fra surveyens **Style** i Deepdots. Mørk tilstand virker på to måder.

## 1. En mørk Style virker af sig selv

Hvis Style-farverne er mørke (fx en mørk *Survey box background color*), skifter popup'en selv til lys tekst: titel, luk-knap, fremskridt, spørgsmål, svar og knapper. Ingen kodeændring, kun et native SDK med understøttelse af mørk tilstand.

## 2. Følg din apps lyse eller mørke tilstand

Hvis din app har lys og mørk tilstand, så angiv de mørke farver i Deepdots (**Survey styling › Dark (optional)**) og fortæl SDK'et, hvilken tilstand der skal bruges.

Android (Kotlin):

```kotlin
val sdk = DeepdotsPopups().apply {
    initialize(
        InitOptions(
            popupOptions = PopupOptions(publicKey = "<your-public-key>"),
            appearance = Appearance.System, // Light | Dark | System
        )
    )
}

// Din app har sin egen knap:
sdk.setAppearance(Appearance.Dark)
```

iOS (Swift):

```swift
popups.setAppearance(appearance: .dark)   // .light, .dark eller .system
```

| `appearance` | Resultat |
|---|---|
| `null` (standard) | Som i dag: Style-farverne bestemmer. |
| `Light` | Lys popup. Style'ens mørke farver ignoreres. |
| `Dark` | Mørk popup med Style'ens mørke farver. Uden dem bruges Style-farven, hvis den allerede er mørk, ellers en standard mørk palet. |
| `System` | Følger enheden (Android `uiMode`, iOS `traitCollection`). |

- `setAppearance(null)` går tilbage til Style-farverne. `getAppearance()` returnerer den aktuelle værdi.
- Med `System` følger popup-rammen et skift, mens den er åben; surveyen beholder den tilstand, den åbnede med.
- På et mørkt kort får en lys brand-knap mørk tekst, så den kan læses.
- Fra Swift angives alle `InitOptions`-parametre, så det nemmeste er at kalde `setAppearance(appearance:)` lige efter `initialize`.
