# Models and Events

## Initialiseringsmodeller

### `InitOptions`

- `debug`
- `popupOptions`
- `provideLang`
- `autoLaunch`
- `renderChrome`
- `metadata`

`renderChrome` (standard `true`, fra **0.4.0**) styrer, om SDK'et tegner popup-"modalen" — det nedtonede scrim og det afrundede kort med elevation, som `PopupView` tegner. Sæt den til `false` for at rendere popuppen gennemsigtig og fuld-bredde, så den falder ind i din egen skærm; surveyen forbliver funktionel (lukkeknap i headeren, footer med back/start/complete/send). Den spejler web/RN-flaget `renderChrome`. Bemærk den native divergens: chromet er native Compose (ikke HTML), og SDK'et auto-monterer stadig et fuldskærms-overlay, så flaget fjerner scrim og kort, men overlader ikke container-monteringen til din app.

## Trigger-modeller

Understøttede trigger-typer i koden:

- `Trigger.TimeOnPage(seconds: Double)`
- `Trigger.Scroll(percentage: Int)`
- `Trigger.Exit(delaySeconds: Double = 0.0)`
- `Trigger.Event(name: String)`
- `Trigger.Click(targetId: String)`
