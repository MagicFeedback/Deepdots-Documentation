# Deepdots Popup SDK

Deepdots Popup SDK er et Kotlin Multiplatform SDK, der lader teams vise in-app-popups og starte surveys på tværs af Android og iOS fra én delt implementering.

## Forretningsværdi

- Reducér tiden til at lancere in-app feedback- og engagement-flows
- Validér mobiloplevelser med de medfølgende Android- og iOS-demoapps
- Administrér popup-kampagner centralt i Deepdots, leveret til appen i runtime

## Hvilket problem det løser

- popups leveret fra Deepdots i runtime
- trigger-baseret visningslogik
- sprog- og path-segmentering
- indlejret survey-rendering via MagicFeedback
- popup-lifecycle-events til analytics og orkestrering

## Korrekt naming

- Kommercielt navn: **Deepdots Popup SDK**
- Repository-navn: `deepdots-popup-mobile-native-sdk`
- Android-pakke: `com.deepdots.sdk:shared-android`
- Swift Package-manifest: `DeepdotsSDK`
- Swift-produktnavn: `DeepdotsSDK`
