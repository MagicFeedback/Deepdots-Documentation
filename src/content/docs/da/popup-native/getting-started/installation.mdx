# Installation

Dette repository eksponerer to primære forbrugsspor:

- Android via Maven Central med `com.deepdots.sdk:shared-android`
- iOS via Swift Package Manager med det binære pakkemanifest `DeepdotsSDK`

## Krav

- Android-apps kompilerer mod Java 17 i dette repository
- Android-eksempelapps bruger `minSdk = 24`
- iOS-distribution målretter **iOS 13+**
- Namespacet for det delte SDK-modul er `com.deepdots.sdk`

## Android

Tilføj den publicerede afhængighed:

```kotlin
dependencies {
    implementation("com.deepdots.sdk:shared-android:0.5.0")
}
```

Android-eksempelappen i dette repository bruger præcis den koordinat.

### Android-eksempelkommandoer

```bash
./gradlew :example-android:assembleDebug
./gradlew :example-android:installDebug
```

## iOS

SDK'et distribueres som en binær Swift-pakke fra [`MagicFeedback/DeepdotsSDK-SPM`](https://github.com/MagicFeedback/DeepdotsSDK-SPM). Den eksponerer biblioteksproduktet `DeepdotsSDK`.

I Xcode: vælg **File → Add Package Dependencies…**, indtast repository-URL'en og vælg version `0.5.0`:

```text
https://github.com/MagicFeedback/DeepdotsSDK-SPM
```

Eller i en `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/MagicFeedback/DeepdotsSDK-SPM", from: "0.5.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "DeepdotsSDK", package: "DeepdotsSDK-SPM")
    ])
]
```

Selve pakkemanifestet er binært:

```swift
// swift-tools-version: 5.7
import PackageDescription

let package = Package(
    name: "DeepdotsSDK",
    platforms: [
        .iOS(.v13)
    ],
    products: [
        .library(name: "DeepdotsSDK", targets: ["DeepdotsSDK"])
    ]
)
```

### iOS-eksempelflow i dette repository

iOS-demoprojektet resolver en lokal pakke fra `spm-local/`. Hvis den lokale XCFramework mangler, så regenerér den først:

```bash
./run_ios_example.sh
```

For at resolve og bygge fra Xcode-værktøjer:

```bash
cd iosApp
xcodebuild -resolvePackageDependencies -project iosApp.xcodeproj -scheme iosApp -destination 'generic/platform=iOS Simulator'
xcodebuild -scheme iosApp -project iosApp.xcodeproj -destination 'platform=iOS Simulator,name=iPhone 16e' build
```

## Offentlige kontra interne pakkedetaljer

- Offentlig forbrugsdetalje: Android-afhængighedskoordinaten og iOS SPM-pakke-/produktnavnene
- Vedligeholderdetalje: release-scripts i `scripts/prepare_sdk_release.sh`, `scripts/prepare_spm_release.sh` og `scripts/prepare_maven_upload_zip.sh`

Disse vedligeholder-scripts er en del af repositoriet, men de er release-værktøjsorienterede snarere end integrationstrin for slutbrugeren.
