The Deepdots REST API lets your backend send feedback and keep your CRM contacts in Deepdots up to date, without installing an SDK. Every call is a plain HTTPS request with a JSON body and a bearer token.

## What you can do

- **Send feedback** — one at a time or in bulk, with answers, metrics and metadata.
- **Manage contacts** — create or update CRM contacts by email, with your own custom fields.
- **Link feedback to contacts** — record who gave each feedback.

Deepdots analyses every feedback you send: topics, sentiment, KPIs and everything else you see in the dashboard.

## Base URLs

| Environment | URL |
|---|---|
| Production | `https://api.deepdots.com` |
| Development | `https://api-dev.deepdots.com` |

Use the development environment while you build and test your integration. It has its own data and credentials.

## What you need from Deepdots

- An API key for each environment, or an API user (email and password) if you sign in instead.
- Your `companyId` and the `integrationId` of each source you send feedback from.

Your Deepdots contact gives you all of these when your integration is set up.
