# Deepdots Popup SDK

Deepdots Popup SDK es un SDK de Kotlin Multiplatform que permite a los equipos mostrar popups in-app y lanzar encuestas en Android e iOS desde una única implementación compartida.

## Valor para negocio

- Reduce el tiempo para activar flujos de feedback y engagement in-app
- Valida experiencias móviles con las apps demo de Android e iOS incluidas
- Gestiona las campañas de popups de forma centralizada en Deepdots, entregadas a la app en tiempo de ejecución

## Qué problema resuelve

- popups entregados desde Deepdots en tiempo de ejecución
- lógica de visualización basada en triggers
- segmentación por idioma y por path
- render de encuestas embebido a través de MagicFeedback
- eventos de ciclo de vida del popup para analítica y orquestación

## Naming correcto

- Nombre comercial: **Deepdots Popup SDK**
- Nombre del repositorio: `deepdots-popup-mobile-native-sdk`
- Package Android: `com.deepdots.sdk:shared-android`
- Manifiesto de Swift Package: `DeepdotsSDK`
- Nombre del producto Swift: `DeepdotsSDK`
