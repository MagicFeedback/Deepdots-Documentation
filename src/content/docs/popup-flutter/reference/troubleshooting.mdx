## No popup appears

- Check that the `publicKey` belongs to the environment you selected: a test account's key with `DeepdotsEnvironment.development`, a production key with the default.
- Check that the popup is active in Deepdots and targets the current screen or event. Turn on `debug: true` and look for `[DeepdotsPopups]` lines in Logcat or the Xcode console.
- Check that your screens reach the SDK: routes need a name for `DeepdotsNavigatorObserver` to report them. See [Navigation](/popup-flutter/guides/navigation/).
- A popup already shown to a user is usually not shown to the same user again. To test it again, use a new `userId`.

## No popups in an Android release build

The plugin declares the `INTERNET` permission, which Flutter only adds to debug and profile builds. If your app removes permissions from merged manifests (for example with `tools:node="remove"`), make sure `android.permission.INTERNET` is kept.

## iOS: `Undefined symbol: _OBJC_CLASS_$_DSDK…` or `Module 'deepdots_popups' not found`

The `EXCLUDED_ARCHS` setting is missing. Add it as described in [Installation](/popup-flutter/getting-started/installation/#4-set-up-ios), for Swift Package Manager or for CocoaPods.

## `PlatformException(no_context)`

`show`, `showByPopupId`, `triggerSurvey` or `close` were called before the app had a visible screen. Call them after the first frame, for example from a button or with `WidgetsBinding.instance.addPostFrameCallback`.

## `flutter pub get` cannot fetch the package

The repository is public, so no credentials are needed. Check that the `url` and `ref` match [Installation](/popup-flutter/getting-started/installation/) (the tag starts with `v`, for example `v1.0.0`) and that your machine and CI can reach github.com.

## Dart SDK version error

The plugin needs Flutter 3.24 or later (Dart 3.5). If your app is on an older Flutter version, tell your Deepdots contact.

## Android: "requires Android Gradle plugin 8.9.1 or higher" or "incompatible version of Kotlin"

Your app was created with Flutter 3.32 or earlier and its Android toolchain is older than the native SDK needs. Raise the Android Gradle plugin, Gradle, Kotlin and `compileSdk` as shown in [Installation](/popup-flutter/getting-started/installation/#apps-created-with-flutter-324-to-332).

## iOS: "The folder FlutterFramework doesn't exist"

Swift Package Manager is enabled on a Flutter version older than 3.41. Turn it off with `flutter config --no-enable-swift-package-manager`; the app then builds with CocoaPods.

## Known limitations

- Installed from git only; not on pub.dev yet.
- Apps created with Flutter 3.24 to 3.32 need the Android toolchain changes from [Installation](/popup-flutter/getting-started/installation/#apps-created-with-flutter-324-to-332).
- `setLanguage()` does not change the language reported in analytics: it is set once, in `init()`.
